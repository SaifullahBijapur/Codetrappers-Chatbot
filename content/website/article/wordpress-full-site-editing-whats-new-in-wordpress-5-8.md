# WordPress Full Site Editing: What’s New in WordPress 5.8

Yusuf Mudagal 23 Dec 2022 2 min read

WordPress Full Site Editing (FSE) is a new feature introduced in WordPress 5.8 that allows users to design and build their entire site directly from the WordPress editor. This means that users can now create custom templates, blocks, and styles without needing to know any code.

CodeTrappers is excited to see the new possibilities that WordPress FSE brings to the table. With this feature, users can easily customize every aspect of their site, from the header and footer to the individual pages and posts. This allows for a greater level of flexibility and creativity in website design.

One of the key benefits of WordPress FSE is the ability to create custom templates. This means that users can design a template for their home page, for example, and then apply that same template to all of their other pages. This can save a lot of time and effort, as users no longer need to design each page individually.

In addition to custom templates, WordPress FSE also introduces a wide range of blocks that can be used to create unique and engaging content. These blocks can be easily added to any page or post, and can be customized with a variety of styles and options.

Overall, WordPress FSE is a game-changing feature that makes it easier than ever for users to design and build their own website. We at CodeTrappers are excited to see the creative and innovative ways that users will utilize this new feature.
