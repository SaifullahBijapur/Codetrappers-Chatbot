# How do I migrate my WordPress website to a new hosting provider?

This process ensures a seamless WordPress migration with minimal downtim

3 Mar 2025 1 min read

1.  **Backup your website** – Use UpdraftPlus or WPvivid to create a full backup.
2.  **Export your database** – Download a copy using phpMyAdmin.
3.  **Transfer files** – Use FTP (FileZilla) to move files to the new server.
4.  **Import the database** – Upload the SQL file to the new host.
5.  **Update the wp-config.php file** – Modify database credentials for the new hosting environment.
6.  **Change domain settings** – Update DNS records to point to the new server.

This process ensures a **seamless [WordPress migration](https://codetrappers.com/migration-for-wordpress/) with minimal downtim**
