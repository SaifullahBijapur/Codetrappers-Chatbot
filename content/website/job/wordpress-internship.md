# WordPress Internship

**Internship**Employment type

### CodeTrappers Internship Program

## WordPress Developer Intern

### Work on live WordPress projects, learn Elementor/Gutenberg, speed optimization & real client work.

-   Remote / Office (Bangalore) / Hybrid
-   Duration: 3 Months
-   Start Date: Immediate / Flexible
-   Full-time opportunity after internship

### About CodeTrappers

CodeTrappers is a WordPress development company based in Bangalore. We build and maintain WordPress websites for businesses, focusing on performance, clean UI, and smooth user experience.

### Internship Overview

We are looking for a passionate **WordPress Developer Intern** who is eager to learn and work on real client projects. You will get hands-on experience in building WordPress websites, customizing pages, fixing bugs, and improving performance with mentorship from our team.

### Responsibilities

As a WordPress Developer Intern, you will:

-   Build and customize WordPress websites using Elementor / Gutenberg
-   Create and edit pages, menus, headers/footers, forms, and sections
-   Install, configure, and manage WordPress plugins (SEO, cache, security, forms, etc.)
-   Assist in **WooCommerce setup** (products, checkout, payments)
-   Fix bugs and UI issues (layout issues, broken sections, CSS fixes)
-   Ensure **mobile responsiveness** across devices
-   Optimize website speed and performance (basic level)
-   Support website maintenance tasks and small updates
-   Coordinate with the team and follow tasks shared in Trello/WhatsApp/Google Sheets

### Required Skills

-   Basic knowledge of WordPress
-   Familiar with **elementor** or **Gutenberg**
-   Basic understanding of website structure (pages, posts, menus)
-   Good learning attitude and problem-solving mindset
-   Strong attention to detail and ability to follow instructions

### Preferred (Good to Have)

-   Basic knowledge of **HTML + CSS**
-   Basic knowledge of **JavaScript / PHP**
-   Experience with **cPanel / Hosting / Domain setup**
-   Knowledge of SEO basics & performance tools (PageSpeed, GTmetrix)
-   Familiarity with plugins like WooCommerce, ACF, WPForms, Contact Form 7

### Who Can Apply

-   Students / Freshers looking to start a career in WordPress
-   Candidates who can dedicate consistent time during internship
-   Candidates interested in a full-time role after internship

### What You’ll Get

-   Real-world WordPress project experience
-   Guidance + mentorship from the team
-   Portfolio-building work
-   Certificate of completion
-   Full-time opportunity for top performers
