1.  ### Latency is the product

    Past roughly a second of silence a caller assumes the line has dropped and starts talking over it. Speech recognition, the model and speech synthesis all have to fit inside that budget, which constrains every other choice on this page.

2.  ### People interrupt, and it has to cope

    Real callers cut in halfway through a sentence. An agent that finishes its script regardless is the thing everyone hates about phone systems, and handling interruption properly is most of the engineering.

3.  ### Speech is not text

    Accents, background noise, hold music, a name spelled out loud, a postcode read as digits. Transcription errors land inside your data unless every value is confirmed back to the caller.

4.  ### Failing gracefully matters more than answering

    The measure of a voice agent is what happens when it does not understand. A fast, clean handoff to a person, with the context passed across, beats a clever recovery every time.

5.  ### Every call is a recording

    Which means consent, retention periods, and in several jurisdictions telling the caller they are speaking to an automated system. That is a design constraint, not a footnote for the legal review.

## What voice costs that chat does not

We would rather set expectations now. Three things make voice materially harder than the other services on this site.

### The economics are per minute

Telephony, transcription, the model and synthesis all bill by usage, so a slow agent is a more expensive one. The unit cost has to be modelled against the cost of the call it replaces before anyone commits.

### Testing means real audio

Accents, poor lines, hands-free in a car, a warehouse in the background. A recorded test set is the only honest way to know whether it works for your callers rather than for us.

### Start with one narrow line, never the main number

A single call type on a separate number, measured against how a person handles the same calls. If it does not beat that, it does not get the main number, and we will tell you so.
