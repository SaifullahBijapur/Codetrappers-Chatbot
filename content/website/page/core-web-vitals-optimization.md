The service

## How it works on each platform

The metrics are the same everywhere. What we can touch is not, so the plan is different for each.

### Shopify

Theme code, app script audit, Liquid rendering and image sizing. Most Shopify slowness is apps, and we show you which ones.

### Webflow

Interactions, embedded scripts, asset sizes and the settings Webflow does expose. Honest about the ceiling where it does not.

### Next.js and React

Bundle analysis, server components, image and font optimisation, hydration cost and third-party loading strategy.

### Laravel and custom PHP

Query profiling, response caching, asset pipeline, queue offloading and server tuning. We read the code, not just the waterfall.

### Magento and other commerce

Full-page cache, catalogue queries, checkout scripts and the extensions nobody remembers installing.

### Static and headless

Build output, CDN rules, image pipeline and the client-side JavaScript that static sites quietly accumulate.
