The service

## What we secure

The same discipline as our WordPress security work, applied to whatever your site is built on.

### Laravel and Symfony

Composer dependencies, exposed debug modes, storage permissions, queue workers and the .env file that should never have been readable.

### Magento, OpenCart and PrestaShop

Card skimmers in checkout JavaScript, compromised extensions, admin URL exposure and the payment flow itself.

### Custom and legacy PHP

Injection points in hand-written code, outdated PHP versions, file upload handling and the includes nobody has looked at in years.

### Servers and hosting

SSH keys, cron jobs, cPanel or Plesk accounts, and neighbouring sites on the same account that were the real way in.

### Credentials and access

Who has access, to what, from where. We rotate everything and set up two-factor and least privilege as part of the clean-up.

### Ongoing protection

Patching cadence, WAF tuning and quarterly review as a retainer, for sites that cannot afford a second incident.
