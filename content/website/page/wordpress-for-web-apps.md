# Web apps built on WordPress

Custom post types, real permissions and API integrations written as versioned code. For sites that have outgrown plugins and become software.

Past a certain point a site stops being pages and starts being software: accounts, permissions, data models, integrations. WordPress handles that well when it is written as code rather than assembled from plugins.

What usually brings people here

## The same four problems, over and over

### You have outgrown the plugin stack

What began as a form and a directory now needs roles, workflow and reporting. That is an application, and it should be built like one.

### The data model is fighting you

Posts and categories bent into a shape they were never meant to hold. Custom post types, real meta and proper relationships fix this at the root.

### Permissions are guesswork

Who can see what, and who can change it, decided by whichever plugin loaded last. Capabilities belong in code you can read and test.

### Everything needs to talk to everything

CRM, billing, support, internal tools. Integrations written as versioned code with retries and logging, not a webhook someone set up once.
